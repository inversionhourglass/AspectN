## 任务 1：建立可验证的比较

新增独立正则基准及验证入口：固定 1/32 条不同规则，交替成功/失败候选；单次调用执行 64 次匹配并按每次匹配归一化。32 条超过 .NET 默认静态缓存容量 15；仅独立基准进程清空并恢复缓存，不修改生产全局设置。

比较预先生成的规范字符串上的静态 API/实例调用，另测真实已编译 AspectN Match 和禁用引擎缓存的完整编译。后者包括解析和绑定，不误称纯 Regex 构造。计时外验证所有输入、状态、诊断和默认 250ms 超时。BenchmarkDotNet 使用两个进程、三轮预热、六轮测量及分配诊断。

单独以独立进程、强制 GC 前后差值估计持有 2,048 份编译计划的存活堆增量，区分首次匹配前/后；重复五次。此值属于整个计划集合的近似值，不能当作单个 Regex 的精确对象图大小，也不能用 MemoryDiagnoser 的分配量替代存活内存。
