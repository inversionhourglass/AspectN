# RM-24 测试夹具生命周期实施计划

**目标：** 生成器测试及路径子测试成功后清理本次夹具，失败时保留并输出路径；`-KeepArtifacts`显式保留成功资料。

**基准：** `60dfb18ae2a8d681eb4b47539ef346e7fb62b9b8`。使用现有检出，不创建worktree；保留历史夹具、README和既有未跟踪文件，不推送。

**结构：** 在`eng/tests/test-artifacts.ps1`集中创建和登记本次GUID目录、验证路径及完成清理。两个现有测试入口用try/finally标记实际完成状态，子进程传播保留开关。每个脚本独立管理自己的夹具；路径子测试失败即停止父入口。

1. 新增`eng/tests/test-artifacts.Tests.ps1`，先观察缺少生命周期实现的失败。覆盖成功清理、显式保留、异常和exit失败保留、历史同级目录保留，以及父目录、同前缀目录、越界路径、非GUID目标和reparse point拒绝；所有删除先验证绝对路径边界。
2. 最小实现共享辅助函数并接入两个入口。清理仅遍历已登记目录；先整体验证目标为固定artifacts子目录下的直接GUID子目录，拒绝基路径/祖先/后代中的链接，再调用LiteralPath递归删除。失败和保留模式只输出路径。
3. 运行辅助回归及原14项生成器、24项路径和8项跨文化检查，验证默认清理和KeepArtifacts透传；用隔离副本注入失败检查真实入口的退出与保留。保存既有夹具快照核验未改，保留本轮取证资料。
4. 同步INV-0018、处置报告与数据及未跟踪清单，运行知识库生成和-Check、全仓文档检查及diff检查，经独立只读审查后仅提交本项。产品、API、语言及CI触发不变，无需.NET矩阵、打包或消费者重验。
