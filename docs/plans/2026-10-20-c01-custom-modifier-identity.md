# C01 方法声明修饰符身份修复计划

目标：仅修复综合报告 C01，使返回/参数签名的自定义修饰符参与方法声明身份，避免泛型形参身份及约束缓存碰撞。

架构：适配器在内部声明身份路径读取 `modreq/modopt`，保留修饰符类型身份及类型/ref 位置；展示文本、DSL 和核心公共 API 保持现有契约。Cecil 声明解析与缓存复用同一身份路径。

技术栈：C#、Mono.Cecil/Fody、Reflection、Roslyn、xUnit。

1. 新增真实 PE 回归：两个同名、同参数方法仅签名修饰符不同，验证 CLR 加载/调用控制、不同声明身份、独立约束及 C01 的 DSL 结果。覆盖 Cecil/Fody 和三适配器一致性。
2. 运行聚焦测试，确认在旧实现上因身份碰撞而失败。
3. 补充内部声明签名编码，同时更新 Cecil 的声明引用校验；运行聚焦及既有闭合声明、返回形状和兼容资产回归。
4. 同步 `GEN-IDENTITY-001/S4–S7`、泛型身份说明、用户边界章节与独立 C01 修复证据；保留原综合报告的历史结论。
5. 执行 Release 构建、完整测试、格式及文档/派生知识库检查，独立审查后仅提交本修复相关文件。

其他 finding 与既有未跟踪文件不纳入提交。不创建 worktree，不推送分支。
