# RM-13 默认依赖版本读取实施计划

**目标：** 用明确 XPath 读取三个默认依赖版本，要求节点唯一且内容非空，保留显式参数优先级。

**架构：** 只修改 verify-packages.ps1 的默认值初始化，不模拟 MSBuild 求值；合法的多 PropertyGroup 布局可以读取。增加初始化探针以执行真实源码前缀，隔离打包副作用；常规 CI 的 Windows 包验证 job 先运行该测试，既有验证步骤与双平台格式检查保持。

**基准：** `31a61600c13a94e9d99d7c5fc40d288bed6be398`。PowerShell 7 测试宿主，目标脚本保持 Windows PowerShell 5.1 可用；在现有检出工作，保留其他 WIP，不推送或发布。

1. 新增 eng/tests/verify-package-versions.Tests.ps1，从真实脚本 AST 提取至 buildProperties 初始化结束，在独立合成仓库执行，检查退出码、诊断、三个值和传给构建的属性。覆盖原布局、无属性节点、多分组/拆分/重排、每项缺失/重复/空白、错误位置及显式全部/部分覆盖；先确认旧实现失败。
2. 使用 /Project/PropertyGroup/<属性名> 查询所有节点，数量不为1或值全空白时给出带文件及属性名的明确错误。保留显式参数分支、XML加载、后续打包及消费者验证；测试两个本地PowerShell宿主。将初始化测试接入现有包验证job。
3. 在全新 artifacts/rm13 子目录运行真实五包及net472/net10.0消费者验证；不修改或复用已有发布目录，不真实签名发布。同步包工程盘点、处置记录、证据和未跟踪清单；文档校验、知识库生成及-Check、工作流结构比较、diff检查、独立只读复核后只提交本项。
