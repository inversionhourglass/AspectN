## 维护者裁决与范围

维护者批准优先合并成员表达式根之后的连续多余输入；保留缺失语法项的独立提示，不按诊断位置统一合并。`method(* Run(..)) a b c d` 从四条逐 token 的 AN1001 改为一条，跨度覆盖 `a b c d`；合法根的语法树保持，编译继续拒绝该输入。

实现只调整核心 Parser 的尾部恢复。扫描仍使用原 NextToken/Lexer，包含中间空白，排除首尾空白；词法错误仍独立收集。finally 保证资源中止时仍保留已扫描部分的尾部位置，外层按原规则处理限制。没有改变词法器、默认额度、取消通道、类型模式入口、公共 API 或诊断快照去重规则。

`method(` 的四条同位置不同消息仍独立保留；缺失外层右括号与多余尾部也保留各自诊断。正式语言第 21 节和结果指南同步限定规则，不将其他恢复路径或全部 AN1001 合并列为本轮承诺。
